--------------------------------------------------------------------------------
  0.  WHAT IS THIS?
--------------------------------------------------------------------------------

Series Forge turns a library of reference images into generative "editions" -
maximal, layered, glitchy collages that can dissolve a chosen subject into
chaos. It analyzes the aesthetic of your images, groups them, generates
matching prompts, frames the results, archives everything, and - crucially -
LEARNS which outputs you like and evolves toward that vibe.

It's one HTML file plus companion .js files. Just open series_forge.html
(double-click, or the "Series Forge" desktop shortcut).


--------------------------------------------------------------------------------
  1.  THE TABS  (top of the window)
--------------------------------------------------------------------------------

  LIBRARY  - import reference images; tag them; auto-group by aesthetic
  FORMULA  - design the look of a single piece; Avant preset; formula codes
  SERIES   - forge a batch (reseed / sweep / decay) + export a video
  BRAIN    - mood boards, aesthetic analysis, prompt generator
  SOURCE   - pick the SUBJECT + the pool (images / groups / boards) for a series
  GALLERY  - archive of every generation; Curator + the Like/Learn/Evolve loop
  FRAME    - drop a finished image into an ornate picture frame

Rough flow: Library -> Brain/Source -> Formula -> Series -> Gallery -> Frame,
then loop back via the Gallery's feedback tools.


--------------------------------------------------------------------------------
  2.  LIBRARY  -  get images in
--------------------------------------------------------------------------------

Import:
  * Drag & drop images (or a whole FOLDER) onto the drop zone.
  * "+ Import Images"  - pick individual files.
  * "+ Import Folder"  - pick a folder; every image inside is imported.

Stored locally (IndexedDB); survives refreshes.

Tagging:
  * Each card has a "tags" box (comma-separated, e.g. "anime, meme, 3d").
  * Tags feed the Formula tag filter and the prompt generator.

Auto-Group by Aesthetic:
  * Set "Groups" (2-6), press "Auto-Group by Aesthetic".
  * Clusters the library into families (e.g. "Dark / Warm / Textured") with a
    palette + thumbnails. Per group: "Save as board" or "Tag".

Also: "Export Manifest (JSON)", "Clear Entire Library".


--------------------------------------------------------------------------------
  3.  IMPORTING FROM PINTEREST  (bulk)
--------------------------------------------------------------------------------

Series Forge can't scrape Pinterest, but gallery-dl (already installed) can
bulk-download a board to a folder that you then Import Folder.

  * Double-click  pin_import.bat , paste a board URL:
        https://www.pinterest.com/<user>/<board>/
    Downloads full-res images to:
        %USERPROFILE%\series_forge_refs\pinterest\<user>\<board>\
  * URL tricks:
        .../<user>/<board>/     one board
        .../<user>/             ALL of that user's boards
  * Then: Library -> "+ Import Folder" -> pick that board folder.


--------------------------------------------------------------------------------
  4.  BRAIN  -  mood boards, analysis, prompts
--------------------------------------------------------------------------------

A "mood board" is a named group of library images defining an aesthetic.

Build / Edit: name it, click images to select, "Save". "+ New", "Select all",
"Clear" help. Saved boards list - click to load/edit.

Analyze (button): reports a color PALETTE, metric bars (Brightness, Contrast,
Saturation, Warmth, Detail/texture, Colorfulness) and descriptor chips + tags.
All offline canvas math - no AI service, no keys.

Apply Aesthetic to Formula: translates the analyzed vibe into Formula controls
(grade, intensity, grain, vignette, glitch, scanlines), jumps to Formula.

Prompt Generator: optional Subject text + Style lean (incl. "Avant / Gay NFT"),
"Generate Prompt", "Reroll", "Copy Prompt".

Forge this mood ->: pins the board's EXACT images AND applies its look, then
previews. (For "draw from these but vary", use the Source tab pool instead.)


--------------------------------------------------------------------------------
  5.  SOURCE  -  the SUBJECT + what a series draws from
--------------------------------------------------------------------------------

This is where you decide the INPUT to a series.

SUBJECT (optional) - the image the series ALTERS:
  * Pick ONE image as the base "subject". It is drawn full-canvas, and the pool
    fragments + formula effects (grade, grain, glitch, DECAY...) layer over it,
    partially obscuring/dissolving it. "Alter" controls how much.
  * This is the signature gay-avant move (the Mifella "dissolving figure").
  * Leave unset for a pure collage. "Clear" removes it.

SOURCE POOL - what the collage/overlays are built from (they COMBINE):
  * Mood Boards      - check saved boards.
  * Aesthetic Groups - "Compute groups", then check clusters.
  * Individual Images- click specific thumbnails.
  * Running count = "Source pool: N images". Empty = whole library.

POOL vs EXACT (important):
  * SOURCE POOL = "draw from these, but still vary" - the engine shuffles/reseeds
    WITHIN your pool, so Reseed still gives varied siblings.
  * "Forge this mood" (Brain) = EXACT images, reproduced precisely.
  Setting a Source pool clears any exact pin so the pool takes effect.


--------------------------------------------------------------------------------
  6.  FORMULA  -  design the look
--------------------------------------------------------------------------------

Collapsible sections. "Preview One" (top-right) renders; the preview column
stays pinned while you scroll. "Avant preset (on-genre look)" sets an instant
gay-avant starting point (Stack, heavy fragments, VHS grade, grain, glitch,
decay, dust/scratches, Avant prompt style) - then set a Subject + Alter.

  COMPOSITION : tag filter, Layout (Stack=default blended vibe / Scatter / Grid /
                Strip), Fragments, Torn fragments, Fragment scale, Rotation.
  GRADE & FX  : Grade (CoD / Bleach / VHS / Sepia / Noir / Mono / Night Vision /
                None), Grade intensity, Film grain, Vignette, Scanlines,
                Glitch / RGB split, and BREAK / DESTRUCTION (see Series > Decay).
  DEGRADATION : Rust, Burn, Cracks, Scratches, Dust, Stains.
  HUD OVERLAY : crosshair, ammo, minimap, killfeed, compass, low-health pulse.
  TRANSMISSION// OVERLAYS : redacted + CLASSIFIED stamps, timecode, UFO,
                conspiracy coords, holo sheen, NFT edition stamp.
  OUTPUT      : Canvas size, Seed (+ "Roll").

  FORMULA CODE : after Preview, a code appears capturing ALL settings, the seed,
  the exact images used, the source pool, and the subject/alter - so it recreates
  the piece exactly. "Copy Code"; paste a code + "Load" to restore a look.


--------------------------------------------------------------------------------
  7.  SERIES  -  forge a batch
--------------------------------------------------------------------------------

Set your look in Formula, then:

  Mode:
    - Reseed : unique siblings (same look, varied images/layout each seed;
               stays within your Source pool).
    - Sweep  : one parameter evolves From -> To across the batch.
    - Decay  : PROGRESSIVE DESTRUCTION - same seed/images, ramps "Break" 0 -> 100
               so ONE composite disintegrates step by step (row jitter -> warp ->
               channel shatter -> datamosh -> melt -> pixel-sort -> slice-scramble
               -> chaos). Perfect for the "dissolving subject" look.

  Count, "Generate Series", "Save All PNG".
  A source note shows what the batch draws from.
  EVERY generation is AUTO-ARCHIVED to the Gallery.

  ANIMATE SWEEP -> VIDEO: renders a sweep/decay as motion and exports .webm.
  Tip: Mode=Sweep, parameter=Destruction/Decay for an animated destruction clip.


--------------------------------------------------------------------------------
  8.  GALLERY  -  archive, Curator, and the FEEDBACK LOOP
--------------------------------------------------------------------------------

Every series lands here automatically (thumbnail + formula code), grouped by
generation. Persists across sessions.

Per edition:
  * Click a thumbnail : enlarge (full-res).
  * "Like"            : heart it (feeds the learning loop - see below).
  * "Download"        : re-renders that edition FULL resolution and saves it.
  * "Download all" / "Delete" / "Clear Gallery".

CURATOR (article-based ranking):
  * "Rank: Gay-Avant NFT" scores every edition on the genre's visual core -
    maximal schizocollage + subject disruption + collage layering + distortion -
    sorts best-first with score % badges, marks the TOP 20.
  * "Save Best -> board" collects the top 20 editions' SOURCE images into a
    "Best of" mood board (use it back in the Source tab to make more like them).
  * "Newest first" returns to the normal view.

THE FEEDBACK LOOP (learns YOUR taste):
  1. HEART the editions that nail your vibe (Like button).
  2. "Learn my vibe" - averages the aesthetics AND recipe params of everything
     you liked into a personal profile (needs >= 2 likes).
  3. "Evolve ->" - applies that profile WITH mutation, pulls from your liked
     source images, switches to Series (reseed) and generates a fresh batch
     that explores around your taste.
  4. "Rank: My Vibe" - sorts the gallery by closeness to YOUR learned profile.
  5. Heart the new keepers -> Learn again -> Evolve again. It converges.
  Status line: "Vibe learned from N likes | M liked now".


--------------------------------------------------------------------------------
  9.  FRAME  -  put art in a frame
--------------------------------------------------------------------------------

Frames live in their OWN library (never used as collage fragments).

  1. "+ Import Frames" / "+ Import Folder".
  2. Click a frame to activate it (opening auto-detected).
  3. Pick SOURCE art: a Gallery thumbnail, or "Use latest preview".
  4. Adjust: Mat / background colour; Inset sliders (L/T/R/B); "Auto-detect
     opening".
  5. "Download Framed PNG" (~1600px, frame's aspect, art cover-cropped).

Handles transparent PNG frames and solid frames alike.


--------------------------------------------------------------------------------
  10.  THE AVANT-GAY NFT WORKFLOW  (the whole point)
--------------------------------------------------------------------------------

A repeatable recipe toward the genre:

  1. LIBRARY : import an appropriated grab-bag (anime, memes, 3D renders, pixel
     art, retro graphics) - a Pinterest board via pin_import.bat is ideal.
  2. SOURCE  : pick a SUBJECT (the figure to dissolve). Set the pool to a mood
     board / aesthetic group of your source material.
  3. FORMULA : hit "Avant preset". Bump Fragments (traitmaxxing density). Set a
     high Alter in Source so the subject gets obscured. Preview.
  4. SERIES  : Reseed for variety, or Decay to disintegrate the subject into
     chaos. Generate. (Auto-archived.)
  5. GALLERY : "Rank: Gay-Avant NFT" to see the strongest. HEART your favorites.
  6. LEARN + EVOLVE : "Learn my vibe" -> "Evolve ->". Heart the best of the new
     batch. Repeat. Each loop sharpens toward your vision.
  7. FRAME the keepers and export.

The genre's signature = a MAXIMAL layered collage that DISSOLVES a central
subject into illegible chaos. In this app that is:
  Subject + high Alter + Stack + high Fragments + Decay/Glitch, from an
  appropriated pool.


--------------------------------------------------------------------------------
  11.  WHAT IS "GAY / AVANT NFT" ART?  (short version)
--------------------------------------------------------------------------------

A grassroots, internet-native, Solana-centered art movement - a "punk rebellion"
against polished Ethereum "fine art". Defined by a conceptual approach and
community more than one style, guided by humor, irony, and the absurd. Visually:
"traitmaxxing" hundreds of layers into hyper-collaged images until the avatar is
completely illegible; appropriation of art history, video games, fashion, memes,
and prior NFTs; deliberately "ugly"/amateur/retro (glitch, MS Paint, gaudy 3D,
neon); camp/queer sensibility; AI + hand editing.

Full distilled definition (from two source articles) lives in the repo at:
  docs/gay_avant_nft.md
This is what the Curator's scoring is calibrated against.


--------------------------------------------------------------------------------
  12.  REPRODUCIBILITY  (formula codes)
--------------------------------------------------------------------------------

A formula code ("FRG1....") encodes everything: settings, seed, the exact image
IDs used, the source pool, and the subject/alter. Save codes in a text file to
rebuild or share pieces. Image IDs are specific to THIS browser's library, so a
code reproduces exactly as long as those images still exist here.


--------------------------------------------------------------------------------
  13.  TROUBLESHOOTING / FAQ
--------------------------------------------------------------------------------

Q: "Save All PNG" only saved one file?
   A: Browsers block bulk downloads. Use the GALLERY - download editions
      individually (reliable), or "Download all" (staggered).

Q: "Evolve" or "Learn my vibe" says nothing happens?
   A: You need at least 2 HEARTED editions in the Gallery first.

Q: The Curator's top picks don't match my taste?
   A: Use the FEEDBACK LOOP instead (Like -> Learn -> Rank: My Vibe / Evolve) -
      that learns YOUR taste, not the generic profile.

Q: My Source pool / Subject seems ignored?
   A: Check the count > 0 and the subject thumbnail is set. Note "Forge this
      mood" (Brain) uses EXACT images and overrides a pool.

Q: A framed image shows white where art should be?
   A: Nudge the Frame inset sliders or press "Auto-detect opening" again.

Q: Nothing renders / "Library empty"?
   A: Import references in the Library tab first.

Q: Is anything uploaded?
   A: No. All local. (gallery-dl, run by you, is the only network tool.)
